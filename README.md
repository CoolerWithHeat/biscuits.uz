# biscuits.uz 🍪

**Live Site:** [https://biscuits.uz](https://biscuits.uz)

`biscuits.uz` is a sleek, modern frontend-only web application created as a dessert and bakery brand example. The app was developed in three variations — Vanilla JavaScript, React (Vite), and Next.js — to demonstrate flexibility in implementation and mastery over multiple modern JavaScript frameworks.

## 🧰 Tech Stack

- **Frontend Versions:**
  - Vanilla JavaScript (ES6+)
  - React (Vite)
  - Next.js (App Router)
- **Styling:** Raw CSS (No frameworks or libraries)
- **Hosting:** Deployed on ** AWS **
- **Other:** Responsive design, semantic code

## 🖼️ Features

- 🍰 Product showcase for a bakery brand
- 📱 Fully mobile-responsive layout
- 🌐 Multi-version architecture: Vanilla, React, and Next.js
- ⚡ Fast-loading static site deployed via AWS infrastructure with asynchronous asset loading
- 🔐 HTTPS-secured domain with SEO-ready HTML structure
